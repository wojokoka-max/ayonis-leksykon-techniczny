# Ayonis Leksykon

Osobisty leksykon pojęć związanych z AI, technologią, tworzeniem stron, kodem, komputerami i projektowaniem.

## Funkcje

- wyszukiwanie po nazwie, definicji, kategorii i tagach;
- grupowanie haseł według kategorii;
- ulubione i ostatnio oglądane hasła;
- dodawanie własnych wpisów zapisywanych lokalnie w przeglądarce;
- widok kafelków, widok listy i tryb ciemny.

Aplikacja jest statyczna i nie wymaga instalowania zależności. Otwórz `index.html` w przeglądarce.
